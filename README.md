Contact Management System

A menu-driven Contact Management System developed in C++ using fundamental Data Structures and Algorithms concepts. The system allows users to add, display, search, update, and delete contacts efficiently.

Features

- Add new contacts
- Display all contacts
- Search contacts using Linear Search
- Update contact details
- Delete contacts
- Phone number validation
- Email validation
- Duplicate phone number and email checking

Technologies Used

- C++
- Data Structures & Algorithms
- GCC Compiler
- Visual Studio Code

Data Structures

- Structures
- Array of Structures
- Linear Search

The project demonstrates the practical application of DSA concepts while improving programming, logical thinking, debugging, and problem-solving skills.
